# Public records request — Arlington County real estate assessment data

**Status:** ready to send. Fill the four bracketed fields and submit.

## Before sending: ask for the data product first

Localities frequently sell a standing assessment extract outside the FOIA
process, which is faster and cheaper than a records request and comes with a
refresh schedule. Call **703-228-3920** (Department of Real Estate Assessments)
and ask:

> "Do you offer a bulk extract or data subscription of the annual assessment
> roll and sales file? If so, what does it cost and how often is it refreshed?"

If the answer is yes, take it — skip the FOIA. Send the request below only if
there is no such product.

## Submit to

- Online: https://foia.arlingtonva.us/
- Department of Real Estate Assessments: 703-228-3920

## Eligibility — read this first

Virginia FOIA entitles **citizens of the Commonwealth** (and media outlets with
circulation in Virginia) to public records. Submit as an individual Virginia
resident, not as an out-of-state entity, or the request can be declined on that
basis alone.

## Request letter

**Subject: Virginia FOIA request — real estate assessment and sales data (machine-readable)**

To the FOIA Officer, Department of Real Estate Assessments:

Under the Virginia Freedom of Information Act (Va. Code § 2.2-3700 et seq.), I
request a copy of the County's real estate assessment and property sales
records, in machine-readable form.

I am a resident of the Commonwealth of Virginia. I am requesting these records
in connection with real estate work in Arlington County.

**Records requested** — one row per real property parcel, current as of the
most recent assessment year:

1. **Parcel identifier** — the real property code (`RPCMSTR`), so the records
   can be joined to the County's published parcel geometry in
   `Open_Data/od_REA_Property_Polygons`. This is the single most important
   field in the request; without it the data cannot be located on a map.
2. **Property address**, including ZIP code
3. **Assessed value** — land, improvement, and total, plus the assessment year
   or effective date each value corresponds to
4. **Most recent sale** — sale price, sale date, deed or instrument reference,
   and **any code indicating whether the transfer was arm's-length / valid for
   assessment purposes** (e.g. a validity, qualification, or transfer-type
   code), together with the code list explaining its values
5. **Property use / land use code** and its description, with the code list
6. **Physical characteristics**, to the extent maintained: finished living
   area, lot size, year built, bedrooms, bathrooms, condition or grade rating
   (with any code lists)

If a multi-year sales history is maintained separately, I would additionally
like sales for the **past twenty-four months** with the same fields.

**Format.** Please provide these in any machine-readable format the Department
already uses in the ordinary course of business — CSV, Excel, or a database
extract are all equally acceptable. Delivery by email, download link, or
physical media is fine. I am not asking the Department to create a new record
or to compile data it does not already maintain; an export of existing files is
what I am after.

**Fees.** Please provide an estimate of charges before incurring them. If any
portion of this request is unusually costly, I would appreciate knowing which
part, so I can narrow it — the parcel identifier, assessed values, and sale
price/date/validity fields (items 1–4) are the ones I actually need, and I am
happy to drop item 6 entirely if it is burdensome.

**Recurring access.** If the Department can provide this on a recurring basis —
annually, quarterly, or whenever the assessment roll is certified — please let
me know the process and cost. A standing arrangement would spare us both
repeated requests.

If any portion is withheld, please cite the specific exemption relied upon and
release the remainder.

I understand a response is due within five working days of receipt. Thank you
for your assistance.

# Public records request — Loudoun County real estate assessment data

**Status:** ready to send. Fill the four bracketed fields and submit.

## Before sending: ask for the data product first

Call **703-777-0260** (Office of the Commissioner of the Revenue) and ask:

> "Do you offer a bulk extract or data subscription of the annual assessment
> roll and sales file? If so, what does it cost and how often is it refreshed?"

If a standing product exists, take it — it is faster and cheaper than FOIA and
comes with a refresh schedule. Send the request below only if it does not.

## Submit to

- **FOIA Liaison, Office of the Commissioner of the Revenue: Susan Breen**
- P.O. Box 8000, Leesburg, VA 20177
- Phone 703-777-0260 · Fax 703-777-0263
- Online FOIA request system: https://www.loudoun.gov/3864/Virginia-Freedom-of-Information-Act-FOIA

Loudoun's own FOIA guidance states that requesters may choose any format the
County uses in the ordinary course of business, and explicitly names **Excel
databases delivered by email** — so ask for exactly that.

## Eligibility — read this first

Virginia FOIA entitles **citizens of the Commonwealth** (and media outlets with
circulation in Virginia) to public records. Submit as an individual Virginia
resident, not as an out-of-state entity.

## Request letter

**Subject: Virginia FOIA request — real estate assessment and sales data (machine-readable)**

Dear Ms. Breen,

Under the Virginia Freedom of Information Act (Va. Code § 2.2-3700 et seq.), I
request a copy of the County's real estate assessment and property sales
records, in machine-readable form.

I am a resident of the Commonwealth of Virginia. I am requesting these records
in connection with real estate work in Loudoun County.

**Records requested** — one row per real property parcel, current as of the
most recent assessment year:

1. **Parcel identifier** — the PIN or parcel key used in the County's published
   GIS parcel layers (`COL/LandRecords`), so these records can be joined to the
   parcel geometry the County already publishes. This is the single most
   important field in the request; without it the data cannot be located on a
   map.
2. **Property address**, including ZIP code
3. **Assessed value** — land, improvement, and total, plus the assessment year
   or effective date each value corresponds to
4. **Most recent sale** — **sale price**, sale date, deed or instrument
   reference, and **any code indicating whether the transfer was arm's-length /
   valid for assessment purposes** (e.g. a validity, qualification, or
   transfer-type code), together with the code list explaining its values

   *Note: the County's published GIS layers include an ownership sale date
   (`VPC_OWN_SALE_DT`) but no sale price, which is why this request is
   necessary.*
5. **Property use / land use code** and its description, with the code list
6. **Physical characteristics**, to the extent maintained: finished living
   area, lot size, year built, bedrooms, bathrooms, condition or grade rating
   (with any code lists)

If a multi-year sales history is maintained separately, I would additionally
like sales for the **past twenty-four months** with the same fields.

**Format.** Please provide an Excel or CSV export delivered by email, or by
thumb drive if the file is large — I understand from the County's FOIA guidance
that these are formats used in the ordinary course of business. I am not asking
the Office to create a new record or compile data it does not already maintain;
an export of existing files is what I am after.

**Fees.** Please provide a cost estimate in advance of incurring charges. If
any portion is unusually costly, I would appreciate knowing which part so I can
narrow it — the parcel identifier, assessed values, and sale
price/date/validity fields (items 1–4) are the ones I actually need, and I am
happy to drop item 6 entirely if it is burdensome.

**Recurring access.** If the Office can provide this on a recurring basis —
annually, quarterly, or whenever the assessment roll is certified — please let
me know the process and cost. A standing arrangement would spare us both
repeated requests.

If any portion is withheld, please cite the specific exemption relied upon and
release the remainder.

I understand a response is due within five working days of receipt. Thank you
for your assistance.
